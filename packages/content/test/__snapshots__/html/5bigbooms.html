5 Big Booms

Parsa is tired of FIT1047. The FIT1047 textbook has nnn pages. Parsa decides to determine the average BOOM Power produced when closing the book quickly and forcefully.

Parsa randomly opens the book to a page, with each page being equally likely to be selected. If the book is opened to a certain page, the BOOM Power is equal to the smaller number of pages on either side of the book (this count can range from 000 to nnn). Given the number of sheets in Parsa's book, calculate the expected BOOM Power. In other words, the expected BOOM Power is given by: ∑i=0nmin⁡(i,n−i)n+1\frac{\sum_{i = 0}^{n} \min(i, n - i)}{n + 1}n+1∑i=0n​min(i,n−i)​ where min⁡(a,b)\min(a, b)min(a,b) is the smaller value of aaa and bbb.

Input

The only line of input contains nnn which is the number of pages in Parsa's book.

Output

Print the expected BOOM Power of the book. Any answer with absolute error not exceeding 10−610^{-6}10−6 will be accepted.

Constraints

  • 1≤n≤2×1091 \le n \le 2 \times 10^91≤n≤2×109
