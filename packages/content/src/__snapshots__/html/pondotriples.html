Problem Statement

You are given an undirected graph with nnn vertices and mmm edges. Pondo would like you to determine the number of 333-cycles in the graph. A 333-cycle (triangle) is a cycle of length 333 in the graph.

Input Statement

Your first line will contain two space-separated integers nnn and mmm (respectively).

Your next line mmm lines will contain two space-separated integers each, uuu and vvv, representing an edge between nodes uuu and vvv.

Output Statement

You should output a single integer representing the number of 333-cycles in the given graph.
