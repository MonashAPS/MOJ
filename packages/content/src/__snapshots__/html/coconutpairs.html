You work at a coconut factory, and your job is to package coconuts into pairs for shipping. Two coconuts can be paired together if the absolute difference between their diameters is at most kkk. Each coconut can be used in at most one pair.

Given the diameters of nnn coconuts, what is the maximum number of disjoint pairs you can form?

Input

The first line contains two integers nnn and kkk, the number of coconuts and the maximum allowed diameter difference for a valid pair.

The second line contains nnn integers, the diameters d1,d2,…,dnd_1, d_2, \ldots, d_nd1​,d2​,…,dn​ of the coconuts.

Output

A single integer: the maximum number of disjoint coconut pairs.

Constraints

  • 1≤n≤1051 \le n \le 10^51≤n≤105
  • 0≤k≤1090 \le k \le 10^90≤k≤109
  • 1≤di≤1091 \le d_i \le 10^91≤di​≤109

Example 1

Input
6 2
1 3 5 2 4 6
Output
3
Explanation

We can have 333 pairs of coconuts by pairing coconuts 111 and 222 (1,3)(1, 3)(1,3), coconuts 333 and 666 (5,6)(5, 6)(5,6), and coconuts 444 and 555 (2,4)(2, 4)(2,4).

Example 2

Input
5 1
1 5 3 2 4
Output
2

Example 3

Input
7 0
1 3 1 2 2 5 4
Output
2
