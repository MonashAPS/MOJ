Meow Meow

Problem Statement

Digger and Rykker (pictured below, taking a break from meowing) like to make noise.

We've categorised the noises they make as follows:

  • hiss: This is represented in text as hi, followed by at least 2 ss.
  • trill: This is represented in text as tr, followed by some non-zero amount of is, and at least 2 ls.
  • burble: This is represented in text as b, followed by some non-zero amount of us, followed by some non-zero amount of rs, followed by a b, followed by some non-zero amount of ls, followed by an e.

We want you to write a program to recognise these.

Input

Your first line of input will be a single integer ttt: the number of noises made.

Next, ttt lines will follow, each containing a single string sis_isi​: the noise made by either Digger and Rykker or a human.

Output

For each sis_isi​, if it is a hiss, trill, or burble noise, output hiss, trill or burble, respectively, on its own line.

If sis_isi​ is none of these, output human noises instead.

Constraints

For all test cases...

  • 1≤t≤1001 \leq t \leq 1001≤t≤100
  • 1≤∣si∣≤1001 \leq |s_i| \leq 1001≤∣si​∣≤100
  • Each sis_isi​ only contains English lower-case alphabet letters.

Explanation

The first 333 lines fit their respective definitions.

  • his does not have two ss.
  • trlll needs at least 1 i.
  • burbble repeats a b when it should not.
  • hello kind of just...does not fit into any of the specified categories.
