Given two integers ~a~ and ~b~, output their sum.

This problem exists so that a fresh MOJ deployment can be checked end to end: it exercises the
problems API, the submission queue, the judge pull protocol and the batch scoring path without
needing a real problem set.

## Input Specification

A single line containing two integers ~a~ and ~b~ separated by a space, with
~-10^9 \le a, b \le 10^9~.

## Output Specification

A single line containing ~a + b~.

## Sample Input 1

```
1 2
```

## Sample Output 1

```
3
```

## Sample Input 2

```
5 7
```

## Sample Output 2

```
12
```
